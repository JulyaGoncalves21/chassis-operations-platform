# Security policy

## Scope

This public repository is a local-only, synthetic demonstration. It must never contain or connect to employer systems or operational data.

## Prohibited content

- Real chassis/VINs, plates, customers, employees, routes, dates or operational volumes
- Internal system, SharePoint/Microsoft Lists, server, network-path or URL names
- Corporate source code, schemas, screenshots, spreadsheets, PDFs, documents, PBIX or MSAPP files
- Credentials, tokens, cookies, browser profiles, certificates or `.env` files
- Outputs, evidence, logs or backups copied from a private environment

## Reporting

If you find accidental sensitive-data exposure, use GitHub's private security-advisory flow. Do not open a public issue with the sensitive value.

## Supported version

Only the current default branch is maintained. This repository is not a production service and does not accept real operational data.
