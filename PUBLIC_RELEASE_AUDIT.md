# Public release audit

## Included

- New local-only modules for normalization, dry-run planning, guardrails, event derivation and synthetic document rendering.
- Invented vehicle snapshots and transfer records.
- Sanitized Power Fx using generic source and field names.
- Architecture, data-model, security and portfolio-page documentation.

## Excluded

- All original MSAPP files and unpacked source packages.
- Production list-sync, browser-download, SharePoint and external spreadsheet adapters.
- Original spreadsheets, PDFs, documents, screenshots, logs, evidence, outputs and backups.
- All executables, BATs, browser profiles, cookies, sessions and `.env` files.

## Replacements and controls

- Identifiers, locations, dates, requests and document content are fictional.
- External configuration values are blank.
- The executable example has no network or external write capability.
- Security scanning is required before staging and again against Git history after commits.

## Limitations

The repository demonstrates component responsibilities and safe planning behavior. It is not an export of the private application, cannot be imported as a complete Power Apps solution and does not reproduce corporate documents.
