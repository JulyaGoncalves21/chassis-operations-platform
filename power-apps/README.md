# Power Apps public documentation

The original MSAPP is not distributed. It may contain environment, application, tenant, connector, list and user metadata. This directory documents the verified navigation and provides selected formulas rewritten against generic source names.

Public names:

- `VehicleLocationRegistry`: current vehicle status and location.
- `VehicleEventHistory`: chronological status/location events.
- `TransferRequests`: origin and destination workflow.
- `DispatchDocuments`: document availability and reference metadata.

The app supports vehicle search, current status, origin/destination context, event history, transfers and dispatch-document access. The public formula is illustrative and cannot connect to the private environment.
